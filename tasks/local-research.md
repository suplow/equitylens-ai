# Local ChatGPT research bridge

User decision: existing ChatGPT account, no additional paid API, local web only.

- [x] Research agent: data, methodology, sector constraints, official sources and missing-data gates.
- [x] Bridge agent: map research to contract, product flow and acceptance criteria.
- [x] Deterministic packet snapshots; mock excluded by default and opt-in practice mode.
- [x] Strict JSON/source reference validation; no claim of factual verification.
- [ ] Designer: working source-entry, export and import UI, responsive and keyboard usable.
- [ ] Test UI, check lint/typecheck/build, inspect browser visuals.
- [ ] Record observed results and remaining limits.

Snapshot IDs detect accidental mismatches, not malicious tampering. Prompt instructions reduce but cannot eliminate model hallucinations/injection. No automatic AI call or financial engine is implemented in this increment.
