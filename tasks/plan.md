# EquityLens AI — Phase 1

Local-only Next.js + TypeScript application. Navy/charcoal design system, restrained mint accent, responsive navigation, all six destinations. No deployment or paid services.

## Slices

1. Foundation: scaffold, typed mock provider, reusable UI primitives and application shell.
2. Working dashboard and stock overview: search, chart ranges, persistent local watchlist, transparent provenance.
3. Financial statements and honest preview pages for valuation, AI analyst and research reports.
4. Verification: lint, TypeScript, production build, browser navigation/search/watchlist/responsive tests.

## Data boundaries

All fixtures are fabricated and labeled MOCK. Source and illustrative timestamp accompany each dataset. No verified data, AI-generated analysis, model output or computed valuation is claimed. AI and valuation execution remain disabled until Phase 2/3. No API key is required in Phase 1.

## Later phases

Deterministic financial engine and tests; server-only AI with citation validation and prompt-injection defenses; verified licensed market-data adapters. PostgreSQL is deferred until server persistence is needed.
